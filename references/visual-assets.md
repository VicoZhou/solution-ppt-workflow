# 视觉资产：选择、制作与检查

## 素材来源决策

| 内容 | 首选 | 备选 | 常见错误 |
|---|---|---|---|
| 标题、页码、长说明、表格 | PPT 原生元素 | 无 | 整页烘焙成图，难修改且易错字 |
| 已实现的功能场景 | 脱敏真实截图 | 依据真实界面生成的示意原型 | 展示不存在的页面或过大 UI 字体 |
| 业务全景/应用架构 | 原生可编辑关系图 | 局部高分辨率生成图 | 堆图标、箭头不表语义 |
| 氛围/场景视觉 | 图像生成 | 合法素材库 | 花哨背景抢走信息层级 |

用户明确指定图片生成、PPT 原生绘制或某个编辑器时，以用户要求为准。不要拿纯文字卡片冒充值得生成的图片；也不要因为图像生成方便，就把需要精确编辑的整页都变成图片。

## 真实截图或原型的流程

1. 先看产品页面，必要时查界面代码和实际字段；确定演示的是哪个用户、哪个动作、哪个状态。
2. 清除或替换真实客户、头像、电话、金额等敏感内容；虚构数据须标注为演示。
3. 截图优先选可读的宽屏或手机原始比例。若截图糊，用同一产品的布局和控件密度生成原型，不发明功能。
4. 生成图只负责内容区；PPT 原生层负责标题、结论、说明、注释和页码。特殊整页视觉经用户同意例外处理。
5. 在实际演示尺寸检验：汉字、生僻字、Logo、数字、状态标签、连线、裁切、像素清晰度。若错误在图片内，修图或重做图片，不叠文本遮盖。

## 风格节奏

相同品牌色与文字规范可以贯穿全稿，但连续页面不应共用完全相同的“三卡片 + 箭头”结构。可在整页蓝图、半幅真实界面、左右图文、前后对比、场景时间线之间切换；选择依据是本页的问题和证据，不是为了变化而变化。背景色与生成图片边缘应融合，图片不应像一张突兀的贴纸。
